This project is a mirror of [pharo-rdbms/glorp](https://github.com/pharo-rdbms/glorp)
intended to be used as a stable dependency on [Buenos Aires Smalltalk](https://github.com/ba-st)
projects.

The `release-candidate` branch can be used as a stable dependency and `upstream`
branch is mirroring the default branch of the upstream repository.
